# مدرسه‌یار معلم | A08 — مرکز تکالیف بومی اندروید (آزمایشی)

این نسخه **ادامه A07** با همان آیکون رسمی آبی، تم بومی آبی/سفید، رابط کاملاً فارسی و راست‌به‌چپ، ورود با اثر انگشت و کارنامه تفصیلی آزمون‌هاست.

## قابلیت‌های تازه

- ورود به **مرکز تکالیف** از صفحه «بیشتر»؛ بدون بارگذاری سایت و بدون WebView.
- دریافت تکالیف و تحویل‌های مجاز معلم در سال تحصیلی فعال، نمایش تعداد تحویل‌ها و موارد تصحیح‌شده.
- ساخت پیش‌نویس، انتشار و ویرایش تکلیف برای کلاس و درس تخصیص‌یافته.
- عنوان، دستور تکلیف، بارم تا ۲۰، نیم‌سال، مهلت شمسی و ساعت ۲۴ساعته، اجازه تأخیر.
- ارسال برای تمام کلاس یا دانش‌آموزان منتخب، با انتخاب چندگانه.
- انتخاب حداکثر **دو** تصویر JPG/PNG/WebP یا PDF از حافظه گوشی؛ هر فایل حداکثر **۶۵۰ کیلوبایت**، طبق اعتبارسنجی سرور.
- مشاهده متن تحویل دانش‌آموز، تعداد پیوست‌ها و مشاهده تصویر/PDF در محیط بومی؛ PDF با پیمایش صفحه‌ها.
- تصحیح نمره در دامنه ۰ تا بارم تکلیف، ثبت بازخورد و ویرایش نمره قبلی.
- تأیید پیش از ذخیره/انتشار و پیش از ثبت نمره. سرور اعلان انتشار و تصحیح را ایجاد می‌کند.
- بازخوانی داده‌های سرور پس از هر ثبت برای پرهیز از نمایش داده قدیمی.

## API و امنیت

- **خواندن**: `GET /api/state` با Bearer token معلم، داده محدودشده توسط `scopedDbForStaff`.
- **ساخت و ویرایش**: `POST /api/staff/homework/p652/save`.
- **تصحیح**: `POST /api/staff/homework/grade`.
- **دیدن فایل پاسخ مجاز**: `GET /api/files/{key}`؛ سرور باید دسترسی معلم به دانش‌آموز را تأیید کند.
- **هرگز** از `POST /api/state` برای ثبت تکلیف استفاده نمی‌کنیم. به این ترتیب داده‌های همزمان سایر معلمان بازنویسی نمی‌شوند.
- پیوست‌ها، پاسخ‌ها و توکن در حافظه جاری‌اند؛ نسخه آفلاین یا کش دائمی داده‌های دانش‌آموزان ساخته نشده است.
- پایگاه داده، سرور، پنل وب و نسخه مادر **هیچ تغییری** نکرده‌اند.

## محدودیت‌های مهم و واقعی

- `GET /api/state` ممکن است برای مدارس با بانک سؤال و فایل‌های حجیم، کند شود یا از سقف **۲۰ مگابایت پاسخ** عبور کند. در آن صورت برای نسخه بعدی یک API خواندنِ سبک مخصوص تکالیف با مجوز مستقل لازم است؛ این بسته چنین API جدیدی روی سرور نصب نمی‌کند.
- اعتبارسنجی پایانی و مجوزها روی سرور انجام می‌شود؛ تغییرات جدید فقط در سورس گوشی هستند.
- فایل‌های پاسخی که در API فایل‌ها موجود نیستند یا توسط سرور مجاز اعلام نشوند، پیش‌نمایش داده نمی‌شوند.
- چون APK در این محیط بیلد نشده و گوشی واقعی تست نشده است، **عملکرد نهایی روی هاست هنوز تأیید نشده**.
- اگر نسخه نصب‌شده A07 مطابق بسته مرجع نیست، برای جلوگیری از ناسازگاری از سورس کامل A08 در شاخه جدید استفاده کنید.

## نصب از GitHub

۱. یا تمام محتوای ZIP سورس کامل را در شاخه/مخزن آزمایشی قرار دهید؛ یا اگر مخزن دقیقاً نسخه A07 است، فقط محتویات `INSTALL/` بسته پچ را جایگزین کنید.
۲. Commit کنید؛ Actions → **Build Native Teacher Android APK** → Run workflow.
۳. پس از موفقیت Build، فایل `Madreseyar-Teacher-A08-Native-Debug-APK` را از Artifacts بگیرید و روی گوشی آزمایشی نصب کنید.
۴. برای بازگشت به A07، فایل‌های `ROLLBACK_TO_A07/` را جایگزین کنید و فایل‌های تازه ذکرشده در `DELETE_ON_ROLLBACK.txt` را حذف کنید.

## تست واقعی پیشنهادی (فقط با حساب و دانش‌آموز آزمایشی)

۱. ورود با رمز و اثر انگشت؛ اطمینان از نبود WebView و حفظ آیکون.
۲. «بیشتر ← مرکز تکالیف»؛ مقایسه فهرست با وب.
۳. ساخت پیش‌نویس فارسی با مهلت شمسی و بارم، مشاهده نتیجه در پنل وب.
۴. ویرایش همان پیش‌نویس؛ حفظ کلاس، گیرندگان و پیوست‌ها.
۵. انتخاب گیرندگان خاص و انتشار آزمایشی؛ دریافت اعلان فقط برای همان دانش‌آموزان.
۶. بارگذاری تصویر و PDF کمتر از ۶۵۰ کیلوبایت؛ رد صحیح فایل بیش از سقف و فرمت نامعتبر.
۷. تحویل پاسخ از حساب دانش‌آموز آزمایشی؛ مشاهده متن و تصویر/PDF روی گوشی معلم.
۸. تصحیح نمره، ثبت بازخورد، و بررسی همان اطلاعات در وب و اعلان دانش‌آموز.
۹. تلاش برای نمره منفی یا بیشتر از بارم؛ باید رد شود.
۱۰. آزمایش مجوز حساب معلم دیگر، اینترنت قطع‌شده، بازگشت اندروید و ورود بیومتریک.

فقط بعد از تست عملی با هاست، اصلاحات تأییدشده وارد سورس مادر شوند.
